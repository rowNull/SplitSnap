# SplitSnap

I live with 6 roommates who share expenses on groceries and I have to add up everyone's receipts by hand each month. SplitSnap is a tool that reads receipt photos and pulls out the total and card last 4 digits so it knows who paid for what. It also separates shared items (groceries) from personal items (clothes, shampoo) and allows you to split the shared items evenly between roommates.
